# Python Environment Setup & Learning Goals

This repository contains the initial setup for Python development and Git version control practices using VS Code.

## Learning Goals

1. **Environment Setup:** Configure Python 3 and VS Code editor workflows.
2. **Version Control:** Initialize a Git repository, stage changes, and create commits.
3. **Python Fundamentals:** Implement entry point guards (`if __name__ == "__main__"`).
4. **Documentation:** Document technical workflows using Markdown.

## How to Run

Run `hello.py` directly using the VS Code Play button or via the terminal:

```bash
python hello.py
